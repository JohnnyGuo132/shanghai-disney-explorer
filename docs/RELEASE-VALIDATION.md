# v1.0.0 验收记录

日期：2026-09-16。对象：本仓库随附的完整静态站点。下表记录实际执行的检查，不代表对全部设备、全部游览路线或全部画面的覆盖。

## 浏览器与交互

环境为 Windows 上的 Codex 内置浏览器；通过本机 HTTP 服务访问 `/shanghai-disney-explorer/` 项目子路径，启用高画质。未记录显卡型号，因此不据此给出硬件最低配置或通用帧率承诺。

| 检查 | 结果 |
| --- | --- |
| 首次加载 | 模型、植物、纹理与界面载入；加载层正常退出 |
| 桌面 1280 × 800 | 城堡近景、全园鸟瞰、昼夜工具和目的地操作可见 |
| 日期与日光 | 设为上海时间 2026-09-16 14:00，场景进入日光状态 |
| 夜间演出 | 60 秒演出运行；在第 53 秒记录到金柳终章、城堡投影与照明。该次诊断未报告粒子丢弃 |
| 搜索 | 搜索「创极速光轮」返回一个对应景点；选中后相机位置保持不变 |
| 路线规划 | 从观演位置规划至创极速光轮观景点，显示约 335 米的场景步行路线 |
| 导航状态 | 开始为 `walking`；暂停为 `paused`；继续恢复 `walking`；结束后路线状态清空 |
| 手机尺寸模拟 390 × 844 | 导航面板、目的地按钮及昼夜控件可见；页面宽度为 390，无横向溢出；可见按钮均位于视口内 |
| 设施演示 | 旋转木马「定格」将设施播放速率设为 0；可以恢复运行 |
| 空搜索结果 | 输入不存在的名称，显示可理解的空结果提示 |
| 运行日志 | 上述交互期间未捕获浏览器 error 或 warning 日志 |

手机检查使用桌面浏览器视口模拟，**不是 iOS / Android 真机或触摸手势验证**。截取的运行状态与画面用于复核操作是否生效，不构成持续性能基准。

## 自动检查与发行制品

资源、JavaScript 语法、模型引用、许可记录和 HTTP 服务行为由项目脚本与 CI 检查。确切执行环境和结果以对应提交的 Actions 日志为准。

发行包通过版本清单和 SHA-256 校验值绑定到一个 Git 提交。下载者可依照 [发行说明](./RELEASING.md) 复核制品；源代码包包含浏览器运行代码与运行资产，不含原始建模工程。

## 本次范围之外

- Safari / Firefox、iOS / Android 真机、低端 GPU 与长期运行压力测试。
- 屏幕阅读器、触屏手势和完整 WCAG 无障碍审计。
- 全园逐栋建模精度、逐条路线复测、设施工程结构和真实室内核验。
- 场景数据不用于现场导航；不承诺测绘级 1:1 或商业主机游戏画质。

## 访问范围

本次发行保存在私有仓库内。GitHub Pages 已撤下，公开自动部署已移除。仓库与旧网站的匿名访问已在 2026-09-16 验证为 HTTP 404；本地 HTTP 预览仅绑定 `127.0.0.1`。
