# 操作指南

[返回项目首页](../README.md)

## 第一次打开

按 README 启动本地服务，打开 `http://127.0.0.1:4173/`。首次进入需要加载模型与纹理。保持浏览器标签页打开，等待加载界面结束。

场景初始视角面向主城堡。可先拖动环顾，再尝试「探索」、昼夜控件与「全园鸟瞰」。如果画面卡顿，将「高画质」切换为「流畅」。

## 去一处景点

**快速看细节**：点击场景中的建筑，相机会移到附近可行走的观景位置。也可以在「探索」中选择区域或搜索名称，再点「看近景」。搜索选中景点本身不会立即移动镜头。

**沿路走过去**：选好目的地后点「导航」，查看从当前位置出发的路线、距离和预计场景漫游时间，再点「开始导航」。路线会在步道与小地图上显示。

- 「暂停导航 / 继续导航」用于中途停留。
- 「查看全程」切换至能看清路线的鸟瞰；「回到步行」回到地面。
- 手动拖动或按方向键可以接管相机并暂停自动行走。
- 改选目的地会清除原路线，需要重新规划。
- 路线无法接入时，可以用「看近景」前往观景点。

距离和时间由虚拟场景路径与行走速度计算，不代表真实园区的通行路线或耗时。

## 自由观察

| 输入 | 行为 |
| --- | --- |
| 鼠标或单指拖动 | 地面环顾；鸟瞰旋转 |
| 鼠标滚轮 | 拉近细节，或拉远至鸟瞰 |
| `W A S D`、方向键 | 地面行走 |
| `Shift` + 行走键 | 加速 |
| 触屏方向按钮 | 地面移动 |
| `/` | 展开搜索并聚焦输入框 |
| `Esc` | 关闭面板，暂停当前自动操作，退出沉浸模式 |

地面行走限制在场景允许通过的区域。围墙、水面及多数建筑不能穿过；选择建筑的近景不等于进入建筑内部。

## 日光、暮色与烟花

底部图标与滑条用于切换日光、暮色、蓝调时刻和星夜。星空与月亮随日期计算，无需单独打开天体面板；月亮是否可见也取决于当时高度与镜头朝向。

点击烟花按钮后，场景会切换到夜间并移至城堡观演位置，随后播放约一分钟的灯光烟花演出。再次使用停止控件可结束演出。切换时间、前往其他近景或开始导航也会结束正在准备或播放的演出。

这是项目自己的视觉编排，不代表园区实际演出内容或排期。

## 游乐设施演示

在地面选中支持演示的设施后，会出现「设施演示」控件，可选择「运行」「慢速」「定格」。这些操作控制设施动画，便于查看结构细节；其他场景动画继续运行。鸟瞰或切换到不支持的建筑时，此面板会隐藏。

## 常见问题

### 终端提示端口被占用

保持现有程序不动，换一个端口：

```sh
npm run dev -- --port 4184
```

打开新的终端地址。停止本次服务时，在该终端按 `Ctrl+C`。

### PowerShell 提示不允许执行脚本

无需更改系统执行策略。在项目目录直接运行：

```sh
node scripts/serve.mjs
```

### 双击 HTML 后模型不出现

通过本地服务打开页面。`file://` 方式不能可靠加载 ES 模块、JSON 和模型资源。

### 画面黑屏、加载失败或中途停止

确认浏览器支持 WebGL 2 并启用硬件加速。解压完整下载包，保留 `dist/` 下目录关系；不要只移动 `index.html`。尝试关闭其他占用显卡的标签页，再刷新或使用页面的重新载入按钮。

仍有问题时，按 [支持说明](../SUPPORT.md) 提供版本、浏览器、复现步骤和控制台错误文字。

### 远处植物闪烁，或烟花时帧率降低

先切换「流畅」，缩小浏览器窗口并关闭其他三维页面。透明植被边缘、远景细线与高亮粒子的呈现受分辨率及抗锯齿影响；查看 [性能说明](./PERFORMANCE.md)。

### GitHub Release 返回 404

仓库和 Release 已公开，无需登录即可下载。请从 [Release 列表](https://github.com/JohnnyGuo132/shanghai-disney-explorer/releases) 检查版本与附件名称，并使用当前发行的完整链接。如果现行链接仍返回 404，可按 [支持说明](../SUPPORT.md) 反馈具体地址。GitHub Pages 尚未启用，请下载源码包后启动本地服务。
