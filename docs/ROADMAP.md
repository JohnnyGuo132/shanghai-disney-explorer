# 已知限制与路线图

[返回项目首页](../README.md)

路线图用于说明后续方向，不构成发布日期或完成承诺。具体改动通过 Issue、PR 与 [CHANGELOG](../CHANGELOG.md) 跟踪。

## v1.0.3 已知限制

- 园区轮廓有地理数据参考，建筑高度、装饰、种植与内景仍包含估算；不是测绘级复刻。
- 建筑内景以部分橱窗和局部陈设为主，不支持逐栋进入。
- 游乐设施提供外观与动画演示，不提供真实运行控制或完整乘坐模拟。
- 场景路径和预计时间用于虚拟游览，没有真实排队、票务、营业和临时封路数据。
- 界面语言以简体中文为主，英文文档不等于界面已完成多语言化。
- 桌面浏览器是主要体验目标；移动设备性能与辅助技术适配仍需扩大验证。
- 没有多设备性能下限承诺，远景细部及透明植被仍有继续改进空间。
- 源码与 Release 已公开，GitHub Pages 尚未启用；目前通过下载包在本机体验。

## 优先改进

### 1. 可靠性与使用体验

- 建立固定浏览器、GPU 与手机真机测试矩阵。
- 记录长时间漫游、场景重载及 WebGL 上下文丢失后的恢复情况。
- 完善键盘焦点、触控尺寸、减少动态效果和文字可读性检查。

### 2. 场景表现

- 按地标建立参考、轮廓、材质与近景细节的验收记录。
- 改进近远景植物过渡、细线抗锯齿、地面接触与阴影一致性。
- 为可进入的有限空间先建立完整动线与内景，再扩展覆盖范围。
- 将烟花、投影和设施演示的视觉编排与帧耗一起评估。

### 3. 开源协作与分发

- 维护素材来源、原创内容 MIT 许可范围与第三方声明；新增素材随改动核对。
- 对安装和启动流程进行非开发者可用性测试。
- 整理适合首次贡献者的问题，完善复现材料与 PR 验证说明。
- 是否恢复公开演示由项目所有者另行决定；现有自动化不执行公开部署。
