# 奇境漫游 · 上海迪士尼 v1.0.1

针对拉近、拉远时画面闪变的修复版本。仓库、发行页和下载附件继续保持私有，GitHub Pages 保持关闭。

## 修复内容

- **缩放时的泛白和明暗跳变**：雾和阴影根据实际镜头高度连续调整，避免地面／鸟瞰模式切换时直接跳到另一组渲染参数。
- **滚轮镜头突跳**：滚轮更新目标距离，镜头平滑跟随，连续缩放时的移动更稳定。
- **地面表面闪烁**：按镜头距离调整近裁剪面，并为重叠地面分层，减少深度精度不足导致的地砖、草坪闪烁。
- **植物突然出现、消失或变色**：视野角度改变时同步刷新植被可见范围；细节等级使用不同的进入／退出阈值，避免边界反复切换，并保持稳定颜色。
- **水面倒影跳变**：镜头移动时刷新反射，减少旧倒影滞留后突然更新的情况。

## 下载与更新

| 附件 | 用途 |
| --- | --- |
| `shanghai-disney-explorer-v1.0.1-source.zip` | 完整项目、运行素材与本地服务，首次体验或更新请选择这个包 |
| `shanghai-disney-explorer-v1.0.1-website.zip` | 纯静态网站，解压后 `index.html` 位于根目录 |
| `SHA256SUMS.txt` | 两个 ZIP 与版本清单的 SHA-256 校验值 |
| `release-manifest.json` | 版本、Git 提交、工具链、文件计数与大小 |

下载需要登录有私有仓库访问权限的 GitHub 账号。更新时先关闭旧版本的本地服务，将新源码包解压到独立目录，以免旧文件混入。在新目录运行：

```sh
node scripts/serve.mjs
```

打开终端显示的地址，通常为 `http://127.0.0.1:4173/`。若此前已打开旧版本，按 `Ctrl+Shift+R` 强制刷新，以重新加载更新后的脚本。需要 Node.js 22 或更新版本，无需安装 npm 依赖。

## 验证范围

本地自动测试共 24 项通过，覆盖本地服务、发行包，以及本次增加的镜头渲染参数、植被视野和细节切换回归检查。资源引用、模型与模块检查仍由项目检查脚本执行。

已在当前 Windows 内置浏览器的 1280 × 608 视口复查高空进入近景、快速反向滚动、升空中断、昼夜缩放边界和城堡演出镜头；没有捕获浏览器错误或警告。详细原因、逐帧参数与检查边界见 [缩放稳定性记录](https://github.com/JohnnyGuo132/shanghai-disney-explorer/blob/v1.0.1/docs/ZOOM-STABILITY.md)。

本次修复针对已定位的缩放闪变来源，不代表所有材质、显卡或视角下都不会出现锯齿或细微闪烁。持续检查结果以该标签对应提交的 Actions 记录为准；尚未完成广泛显卡、Safari / Firefox 与 iOS / Android 真机验证。v1.0.0 的浏览器验收记录和展示截图保留在 `docs/RELEASE-VALIDATION.md` 与 `docs/media/`，不将历史记录视为本补丁的新增设备验证。
