# 奇境漫游 · 上海迪士尼 v1.0.2

修正主城堡底部像垫着矩形展示板的外观。仓库、发行页和下载附件继续保持私有，GitHub Pages 保持关闭。

## 修复内容

- **移除突出的矩形底板**：原模型保留了两块约 47 × 34 米的矩形底板，分别与砂岩、石灰石材质的建筑几何合并。补丁仅移除这两块底板的 24 个三角面，保留墙脚、塔基及其余建筑细节。
- **墙基与广场接地**：按真实墙基高度重新定位城堡，让建筑底部与现有铺地衔接，避免移除底板后出现悬空。
- **保留已有稳定性修复**：继续包含 v1.0.1 的平滑缩放、雾与阴影连续变化、地面分层及植被稳定性调整。

## 下载与更新

| 附件 | 用途 |
| --- | --- |
| `shanghai-disney-explorer-v1.0.2-source.zip` | 完整项目、运行素材与本地服务，首次体验或更新请选择这个包 |
| `shanghai-disney-explorer-v1.0.2-website.zip` | 纯静态网站，解压后 `index.html` 位于根目录 |
| `SHA256SUMS.txt` | 两个 ZIP 与版本清单的 SHA-256 校验值 |
| `release-manifest.json` | 版本、Git 提交、工具链、文件计数与大小 |

下载需要登录有私有仓库访问权限的 GitHub 账号。更新时先关闭旧版本的本地服务，将新源码包解压到独立目录，以免旧文件混入。在新目录运行：

```sh
node scripts/serve.mjs
```

打开终端显示的地址，通常为 `http://127.0.0.1:4173/`。若此前已打开旧版本，按 `Ctrl+Shift+R` 强制刷新，以重新加载更新后的模型与脚本。需要 Node.js 22 或更新版本，无需安装 npm 依赖。

## 验证范围

现有 24 项自动测试、资源引用与模块检查通过。城堡模型 glTF 校验无错误、无警告，并完成几何解码对照及浏览器日间正面、墙脚近景、夜间正面与背面检查。原因、接地方式和实际前后画面见 [城堡接地记录](https://github.com/JohnnyGuo132/shanghai-disney-explorer/blob/v1.0.2/docs/CASTLE-GROUNDING.md)。

检查重点为矩形底板移除、墙脚和塔基保留，以及近景与鸟瞰下的地面衔接。持续检查结果以该标签对应提交的 Actions 记录为准；尚未完成广泛显卡、Safari / Firefox 与 iOS / Android 真机验证。v1.0.0 的浏览器验收记录和展示截图保留在 `docs/RELEASE-VALIDATION.md` 与 `docs/media/`，不将历史记录视为本补丁的新增设备验证。
