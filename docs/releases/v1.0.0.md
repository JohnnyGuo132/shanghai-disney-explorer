# 奇境漫游 · 上海迪士尼 v1.0.0

首个完整私有发行版。可以在本机浏览器运行、检查源码并继续维护；本次发行保持仓库私有，公开演示已下线。

## 本版包含

- 8 个主题区域、22 个主要目的地，地面漫游、建筑近景与全园鸟瞰。
- 从当前位置规划的场景步行导航，支持开始、暂停、继续和路线预览。
- 日光、暮色、星夜，按上海日期计算的太阳、月相与星空。
- 多种烟花、城堡分区灯光和投影演示，以及部分设施的慢速、定格控制。
- 中英文项目介绍、真实运行截图、操作与架构文档、路线图和素材许可索引。
- Linux / Windows 持续检查、本地 HTTP 服务测试、版本化发行包与 SHA-256 校验文件。

## 本机启动

解压源码包，安装 Node.js 22 或更新版本，在项目目录运行：

```sh
node scripts/serve.mjs
```

打开终端显示的 `http://127.0.0.1:4173/`。不用安装 npm 依赖；请通过 HTTP 运行，不要直接双击 HTML。

## 验证范围

资源引用、JavaScript 语法、模型结构、许可记录、本地服务路径边界和发行包防错检查均纳入验证。浏览器检查覆盖 1280 × 800 桌面布局与 390 × 844 视口模拟，包含搜索、导航启停、设施定格、日夜和烟花。

详细结果与原始运行截图见仓库中的 `docs/RELEASE-VALIDATION.md`，自动检查见本标签对应提交的 Actions 记录。手机尺寸模拟不等同于 iOS / Android 真机测试。

## 已知限制

场景是依据公开地图和照片制作的非官方近似重建。建筑内部覆盖有限，无真实排队、营业数据或设施乘坐模拟；不用于现场导航。尚未完成广泛机型、Safari / Firefox、真机触控、完整无障碍和持续 GPU 压力验证。

源码包包含网页代码与运行资产，不包含完整原始建模工程。第三方素材与数据继续遵循各自许可；本次私有发行没有为整个项目新增统一开源许可。
