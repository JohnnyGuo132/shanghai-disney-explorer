## 下载与启动

普通体验和开发请选择 `shanghai-disney-explorer-v1.0.3-source.zip`。解压后安装 Node.js 22+，在项目目录运行：

```sh
node scripts/serve.mjs
```

打开终端显示的 `http://127.0.0.1:4173/`。无需安装 npm 依赖。

也可以克隆仓库：

```sh
git clone https://github.com/JohnnyGuo132/shanghai-disney-explorer.git
cd shanghai-disney-explorer
node scripts/serve.mjs
```

`shanghai-disney-explorer-v1.0.3-website.zip` 用于静态 HTTP 服务；`SHA256SUMS.txt` 与 `release-manifest.json` 用于完整性核对和版本追溯。详见 [发行指南](https://github.com/JohnnyGuo132/shanghai-disney-explorer/blob/v1.0.3/docs/RELEASING.md)。
