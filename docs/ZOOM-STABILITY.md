# v1.0.1 缩放闪烁修复记录

日期：2026-09-16。

## 问题与原因

录屏中最明显的是鸟瞰转入建筑近景时整幅场景突然泛白，以及持续拉远进入鸟瞰时亮度突然改变。旧实现先切换 `aerial` 导航模式，再移动相机，但雾密度与阴影投影也立即跟着这个布尔值切换。相机还在约 720 米高空时，雾密度就会从约 `0.000183` 变为地面的 `0.00105`；镜头位置尚未到达，渲染条件已经改变。

另有三个局部问题会放大不稳定感：

- 近裁剪面一直只有 0.15 米，而道路与广场相隔约 5 毫米；高空下深度精度不足。
- 树木越过 150 米高度时整批切换简化模型；原地改变视野时，植被的可见范围缓存没有及时刷新。
- 水面反射连同反射投影固定每 100 毫秒更新一次，快速移动时会显得不连贯。

## 修复

- 雾、阴影范围与阴影锚点由**实际相机高度**连续计算，与步行／鸟瞰按钮的状态分离。
- 地面视野和鸟瞰距离均使用平滑缩放；连续反向滚动不会让两套滚轮处理互相覆盖。
- 建筑飞行的视野随路径插值；中途取消升空时保留当前姿态，避免轨道控制器强制调整镜头。
- 保留地面 0.15 米近裁剪面，高处连续增加深度精度；重叠地面图层另设稳定的深度优先次序。
- 植被细节按三维距离和投影大小选择，保留切换滞回；草花逐渐缩小淡出，颜色绑定到植株自身编号。
- 相机或投影变化时刷新水面反射，静止时保留节流。

## 验证

自动检查共 **24 项测试通过**，其中 9 项新增回归覆盖高度连续性、地面深度精度、不同帧率下的缩放响应、滚轮单位、缩放范围与植被细节切换。资源引用、模型与脚本检查也通过。

浏览器检查使用当前 Windows 的 Codex 内置浏览器，高画质，1280 × 608 视口，以接近反馈录屏的宽高比重现问题：

| 场景 | 实测结果 |
| --- | --- |
| 从鸟瞰进入建筑近景 | 模式切换相邻两帧的高度为 720 → 718.82 米，雾密度为 0.000183333 → 0.000183497，未跳为地面浓雾 |
| 地面拉远进入鸟瞰 | 模式切换时高度为 1.8 → 1.803 米，两帧雾密度均为 0.00105 |
| 快速拉近后反向拉远 | 视野平滑追踪目标；相机位置与地面雾密度保持不变 |
| 鸟瞰滚轮边界 | 拉远目标可达 6000 米，拉近最终约 12.001 米；保留原范围 |
| 中途按 Esc | 退出升空过渡并保留当前姿态，未触发轨道俯仰限制造成的跳位 |
| 夜景缩放 | 持续拉近至近景正常，未捕获浏览器错误或警告 |
| 城堡演出镜头 | 正常到达观演点，视野为 66°；演出第约 45 秒仍在运行，城堡投影开启，粒子未丢弃 |

这是针对本次反馈的单一环境回归，并非跨 GPU 性能基准。按钮直接切换“全园鸟瞰”仍会主动重置到全园构图；这与相机尚未移动时的渲染闪白不同。远处细线与叶片边缘仍可能有子像素锯齿，尚不承诺所有显卡上完全没有任何闪纹。
